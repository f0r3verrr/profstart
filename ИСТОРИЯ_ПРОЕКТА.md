# История проекта ПРОФСТАРТ+

Документ описывает всё, что было сделано в проекте за время разработки.

---

## 1. Создание сайта с нуля

- **Одностраничный сайт** для ООО «Профстарт+» — фронтовая часть.
- **Адаптивная вёрстка**: корректное отображение на ПК и мобильных устройствах.

---

## 2. Дизайн и стили

- **Опора на логотип**: шестиугольник, колба с листом, заводские трубы — отражены в декоративных элементах и цветах.
- **Цветовая палитра**: изначально фиолетовый, зелёный, серый; позже **сдвинута в сторону синего**, чтобы сайт лучше соответствовал синему из логотипа (переменные `--purple-*` переведены в синие оттенки: `#1e3a5f`, `#2d5a8c`, `#3d6ba6` и т.д.).
- **Шрифты**: Unbounded (заголовки), Montserrat (текст) — Google Fonts.
- **Анимации**: плавные переходы, появление блоков при скролле (Intersection Observer), «плавающие» декоративные фигуры в hero, пульсация иконок у заголовков секций, hover-эффекты на кнопках и карточках.
- **Фон**: градиент с лёгкой текстурой (noise overlay).

---

## 3. Структура страницы

| Секция | Содержание |
|--------|------------|
| **Шапка (header)** | Навигация по якорям, кнопка Telegram-бота (добавлена позже), на мобильных — бургер-меню. |
| **Hero** | Заголовок, подзаголовок, логотип ПРОФСТАРТ+ и кнопка «Узнать больше» (ведут к секции «О компании»). |
| **О компании** | Цель и миссия, связь с Фондом содействия инновациям, уникальная площадка, приглашение к партнёрству. |
| **Партнёры** | Заглушка с приглашением стать партнёром. |
| **Маршруты** | Три карточки: экскурсии на производство, встречи с экспертами, практические форматы. |
| **Контакты** | Информация об ООО «Профстарт+» и блок для контактных данных. |
| **Реквизиты** | Текст о том, что реквизиты носят информационный характер. |
| **Футер** | Текст о поддержке Фонда (ФГБУ), логотип ФАСИ, копирайт по центру. |

---

## 4. Правки по ходу разработки

### Шапка
- **Убран логотип** из header — осталась только навигация.
- **Навигация по центру**; на мобильных бургер-меню справа (чтобы не смещать центр).
- **Добавлена кнопка Telegram**: ссылка на https://t.me/profstartbot, иконка + текст «Telegram Бот», слева в шапке; на узких экранах показывается только иконка.

### Hero (первый экран)
- Блок с логотипом и кнопкой **упрощён**: убрана большая белая карточка с градиентной рамкой и шестиугольной обрезкой.
- Остались **логотип сверху и кнопка «Узнать больше» снизу** (одна ссылка на секцию «О компании»).
- **Размер логотипа в hero** увеличен (на мобильных 150px по высоте, на десктопе 190px).

### Футер
- **Копирайт** («© ООО «Профстарт+». Информационный сайт.») **выровнен по центру**.
- Логотип ПРОФСТАРТ+ (`logo.png`) **удалён** из футера.
- **Логотип ФАСИ** (`head_logo_fasie.png`) **добавлен рядом с текстом** о поддержке (слева от текста на десктопе, сверху на мобильных); размер 88px по высоте.
- **Текст в футере**: «Проект создан при поддержке Федерального Государственного бюджетного учреждения «Фонд содействия развитию малых форм предприятий в научно-технической сфере» в рамках программы «Студенческий стартап» федерального проекта «Технологии».»

### Восстановление после сбоя
- После случайного удаления **восстановлены** `index.html` и `styles.css` в актуальном виде.

## 5. Git и GitHub

- Инициализирован **git-репозиторий**, добавлен **.gitignore** (системные и редакторские файлы).
- Настроен **remote** и выполнен **push** в репозиторий: https://github.com/f0r3verrr/profstart
- Ветка **main**; последующие правки (цвета, футер, кнопка Telegram) **залиты на GitHub** отдельными коммитами.
- В **README.md** добавлена инструкция по включению **GitHub Pages** (Settings → Pages → Deploy from branch `main`, root). Сайт доступен по адресу: **https://f0r3verrr.github.io/profstart/**

---

## 6. Итоговый состав проекта

- `index.html` — разметка одностраничника.
- `styles.css` — стили, переменные цветов, адаптив, анимации.
- `script.js` — открытие/закрытие мобильного меню, анимация появления блоков при скролле.
- `logo.png` — логотип ПРОФСТАРТ+.
- `head_logo_fasie.png` — логотип Фонда (в футере).
- `README.md` — описание проекта и инструкция по GitHub Pages.
- `.gitignore` — исключения для git.
- `ИСТОРИЯ_ПРОЕКТА.md` — этот файл.

Проект готов к использованию и дальнейшему обновлению через GitHub.
